# Plan: Веб-приложение контроля обходов охранников

## Обзор
Веб-приложение для приёма, хранения и управления отчётами обхода от Android-приложения (охранники). HTML/PDF отчёты сохраняются, отображаются в интерфейсе с возможностью сортировки, просмотра, сохранения, пересылки и печати. Простой логин — один администратор.

**Стек:** Spring Boot + Vue.js SPA + H2 (встроенная БД)

---

## Этап 2: Backend — Модель и репозитории

### 2.1. Сущность Report
**Файл:** `src/main/java/com/administratorjhrana/model/Report.java`
```
Поля:
- id (Long, primary key)
- title (String, optional) — название отчёта
- guardName (String) — имя охранника
- date (LocalDateTime) — дата обхода
- htmlContent (String, optional) — HTML-текст отчёта
- pdfUrl (String, optional) — путь к сохранённому PDF
- htmlUrl (String, optional) — путь к сохранённому HTML
- filePath (String, optional) — путь к оригиналу файла
- sentUrl (String, optional) — ссылка из Android-приложения
- size (Long) — размер файла
- uploadedAt (LocalDateTime) — время загрузки
- notes (String, optional) — примечания
```

### 2.2. Сущность User
**Файл:** `src/main/java/com/administratorjhrana/model/User.java`
```
Поля:
- id (Long, primary key)
- username (String, unique)
- password (String, BCrypt)
```

### 2.3. ReportRepository
**Файл:** `src/main/java/com/administratorjhrana/repository/ReportRepository.java`
- `findByOrderByUploadedAtDesc()` — новые первыми
- `findByDateBetween(LocalDate, LocalDate)` — фильтрация по дате
- `findByGuardName(String)` — по имени охранника
- `searchByTitle(String)` — поиск по названию

## Этап 4: Backend — Контроллеры и безопасность

### 4.1. SecurityConfig

- Разрешить H2 Console (X-Frame-Options)

```

GET    /api/reports/{id}         — детали отчёта
PUT    /api/reports/{id}         — редактирование метаданных
DELETE /api/reports/{id}         — удаление
GET    /api/reports/{id}/html    — просмотр HTML в браузере
GET    /api/reports/{id}/pdf     — просмотр PDF в браузере
GET    /api/reports/{id}/download — скачивание файла
POST   /api/reports/{id}/email   — отправка на email
```

### 5.3. Ключевые компоненты

**LoginView.vue**
- Простая форма логина (username + password)
- Вызов `/api/auth/login`
- Перенаправление на `/reports` при успехе

**ReportsView.vue**
- Загрузка списка: `GET /api/reports?page=0&size=20&sortBy=uploadedAt&direction=DESC`
- Отображение `ReportTable.vue`
- Фильтры: `ReportFilter.vue` (дата от/до, охранник, поиск по названию)
- Пагинация внизу
- Кнопка «Загрузить отчёт» (открывает `UploadModal`)

**ReportTable.vue**
```
Колонки:
- № (индекс)
- Дата и время загрузки (сортируемо)
- Имя охранника
- Название
- Тип (HTML / PDF / Оба)
- Размер
- Действия (👁 Просмотр, ⬇ Скачать, 📧 Переслать, 🖨 Печать, ❌ Удалить)
```
- Сортировка по клику на заголовок колонки
- Клик по строке — открытие `ReportCard.vue` (модалка)

**ReportCard.vue**
- Модалка с деталями отчёта
- Табы:「Просмотр」|「Информация」
- Tab「Просмотр」: iframe/embed HTML или PDF viewer
- Tab「Информация»: редактирование title, guardName, date, notes + кнопки (сохранить, переслать, печать, скачать)

**ReportPreview.vue**
- `iframe src="/api/reports/{id}/html"` — для HTML
- `<embed src="/api/reports/{id}/pdf">` — для PDF

**ReportActions.vue**
- 「Скачать」→ `GET /api/reports/{id}/download`
- 「Переслать на email」→ `POST /api/reports/{id}/email` (с полем ввода email)
- 「Печать」→ `window.print()` или `/api/reports/{id}/html` в новом окне
- 「Удалить」→ `DELETE /api/reports/{id}` с подтверждением

**UploadModal.vue**
- Загрузка файла: `POST /api/reports` (multipart)
- Или вставка URL: `POST /api/reports` (JSON с url)
- Поля: охранник, дата, название (автозаполнение если возможно)

- Backend: `:8080` (Spring Boot)

## Порядок выполнения
1. Настроить Maven-проект (pom.xml, application.yml, структура)
2. Создать модели (Report, User) и репозитории
3. Реализовать StorageService + ReportService
4. Реализовать SecurityConfig (один админ) + AuthController
5. Реализовать ReportController (все REST endpoints)
6. Создать Vue.js фронтенд (логин + список отчётов + предпросмотр)
7. Добавить функции: фильтрация, сортировка, сохранение, пересылка, печать
8. Протестировать полный цикл: Android → Backend → Frontend

## Верификация
1. `mvn spring-boot:run` — backend запускается
2. `npm run dev` во frontend — Vue запускается на :5173
3. Логин под админом (admin/admin123) — вход на дашборд
4. POST multipart файл (HTML/PDF) от Android → файл сохраняется
5. GET `/api/reports` — список отчётов с пагинацией
6. Просмотр HTML/PDF в интерфейсе — отображается корректно
7. Редактирование метаданных — сохраняется в БД
8. Скачивание файла — файл сохраняется на диск
9. Фильтрация по дате/охраннику — работает
10. Печать — открывается диалог печати браузера
